# پرتال یکپارچه فرآیندهای سازمانی — پخش قطعات یدکی

سامانه تمام‌استک (Full-Stack) مدیریت زنجیره فروش تا تحویل، تایید دوگانه مالی و صندوق چک‌ها، و صف تامین ۵۰ برند قطعات یدکی خودرو (ایران‌خودرو و سایپا).

## ساختار پروژه

- `server.ts` — نقطه ورود سرور Express + Vite
- `server/db.ts` — پایگاه‌داده SQLite رابطه‌ای (`better-sqlite3`) با جدول‌های تفکیک‌شده (`users`, `sessions`, `settings`, `orders`, `order_documents`, `checks`, `check_attachments`, `procurement_items`, `audit_logs`, `files`)
- `server/routes.ts` — مسیرهای REST و SSE با احراز هویت سمت سرور (`Bearer` در حافظه)، کنترل دسترسی نقش‌محور (RBAC)، قفل خوش‌بینانه نسخه و اعتبارسنجی بایت‌های جادویی فایل‌ها
- `src/shared/types.ts` — تعاریف مشترک TypeScript
- `src/shared/workflow.ts` — منطق خالص کسب‌وکار، فیلتر نقش‌ها، محاسبه مغایرت کارتن، مهاجرت بدون تکرار و اعتبارسنجی فایل‌ها
- `src/shared/workflow.test.ts` — آزمون‌های واحد (`node:test`)
- `src/components/` — رابط کاربری ماژولار React (فاز ۱ فروش، فاز ۲ مالی و صندوق چک، فاز ۳ تامین، مودال‌ها و تنظیمات امنیتی)

## راه‌اندازی

1. نصب وابستگی‌ها: `npm install`
2. اجرای محیط توسعه: `npm run dev`
3. ساخت نسخه تولید: `npm run build` و اجرا با `npm start`
4. در اولین اجرا، صفحه «راه‌اندازی اولیه سامانه» نمایش داده می‌شود تا مدیرعامل رمز عبور اختصاصی خود را تعیین کند (هیچ رمز پیش‌فرضی در کد ذخیره نشده است). همچنین می‌توان متغیر `CEO_INITIAL_PIN` را در محیط سرور تنظیم کرد.
